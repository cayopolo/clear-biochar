# CLEAR Biochar Web App

## About

CLEAR is a standard for data requirements when publishing research on Biochar. This web app aids metanalysis by standardising the data collected in publications on Biochar research.

**Live Site**: https://cayopolo.pythonanywhere.com/

## Local Development

### Requirements
- Python >= 3.12
- [uv](https://docs.astral.sh/uv/)

### Setup

```bash
uv sync
uv run main.py
```

The app will be available at `http://localhost:5000`.

## Deployment

This app is deployed on [PythonAnywhere](https://www.pythonanywhere.com/).
